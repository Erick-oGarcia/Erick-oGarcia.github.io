Toolshop Quality Harness (personal project)
github.com/Erick-oGarcia/toolshop-quality-harness

A full-stack quality harness for a real e-commerce demo app (Toolshop), self-hosted with Docker Compose: UI, API and database checks live in the same Playwright/TypeScript suite, running in GitHub Actions CI. Every check was shown failing before being trusted (docs/detection-proof.md).

  • Tests read the database as a source of truth independent from the application — the check caught the API returning HTTP 200 for products already deleted from the database, a defect neither a UI nor an API test would catch.
  • k6 performance gate with a budget auto-calibrated from the same machine in the same run (p95 of 126 ms on the laptop vs 53 ms on the GitHub runner), instead of a fixed millisecond threshold.
  • Consumer-driven contract with Pact: the client reads 5 fields out of a 12-field payload and the contract demands only those 5, leaving the provider free to evolve everything else.
