Projetos

Toolshop Quality Harness (projeto pessoal)
github.com/Erick-oGarcia/toolshop-quality-harness

Harness de qualidade full-stack para um e-commerce real (Toolshop), self-hosted com Docker Compose: UI, API e banco na mesma suíte Playwright/TypeScript, com CI no GitHub Actions. Toda checagem foi demonstrada falhando antes de ser confiada (docs/detection-proof.md).

  • Os testes leem o banco como fonte de verdade independente da aplicação — a checagem expôs a API devolvendo HTTP 200 para produtos já removidos do banco, falha que nem teste de UI nem de API pegaria.
  • Gate de performance em k6 com orçamento auto-calibrado na própria máquina do run (p95 de 126 ms no laptop vs 54 ms no runner do GitHub), em vez de limite fixo em milissegundos.
  • Contrato consumer-driven com Pact: o cliente lê 5 campos de um payload de 12 e o contrato exige apenas esses 5, mantendo o provedor livre para evoluir o resto.
Stack: Playwright | TypeScript | Docker Compose | k6 | Pact | MySQL | Oracle | GitHub Actions | Node.js | ESLint/Prettier
